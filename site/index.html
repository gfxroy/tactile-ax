Let AI agents click
any Linux app by name.

Not by pixels. tactile reads the buttons, fields and menus an app already exposes, so an agent can say “click Save” and it just works.

pip install tactile-ax
$ tactile tree --app gedit
[a0] application "gedit"
  [a0.0] frame "Untitled Document"
    [a0.0.2] push button "Save"
    [a0.0.5] text "Document"
$ tactile type 'text:Document' 'Hello'
typed into text "Document"
$ tactile click 'push button:Save'
clicked push button "Save"
# same tools over MCP: tactile-mcp

Any desktop

GNOME, KDE, X11 or Wayland. It uses the accessibility layer every Linux desktop already has.

Built for agents

A short text tree that costs few tokens, JSON on request, and an MCP server for Claude, Grok and others.

No screenshots

It acts on real buttons by their name, so a theme change or a moved window won't throw it off.
